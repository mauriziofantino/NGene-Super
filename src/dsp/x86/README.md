# x86 SSE2

`fft_sse2.S`: GNU/Clang, ABI System V/Win64 and Mach-O. `fft_sse2.asm`: MASM for MSVC x64. No AVX instructions are required. Shared C code handles plans, permutation and stage scheduling. SSE2 fuses the first three stages into an eight-point register codelet, validates input headroom and processes four complex butterflies per main iteration. The production C path gathers bit-reversed input in quartets and completes independent 512-point subtrees before global stages. Every original Q14 product floor and per-stage scaling boundary is retained; the scalar oracle keeps its independent scatter permutation and breadth-first schedule. See [FFT review](../../../docs/service/FFT_REVIEW.md) and the [benchmark](../../../benchmarks/fft/README.md).

`fft_sse2_32.c` implements the same register codelet, vector headroom check and four-butterfly kernel with SSE2 intrinsics for 32-bit Intel-compatible targets. The compiler handles the platform's 32-bit ABI; the kernel requires no 64-bit general registers or AVX instructions. Only this source is compiled with `/arch:SSE2` or `-msse2`. A CPUID feature check, including the EFLAGS-ID probe, selects SSE2 once when each immutable FFT plan is created; processors without SSE2 execute the independent scalar path. The feature check itself uses no vector instructions. Q14 coefficients, arithmetic floors and endpoint behavior match the x86-64 implementation bit for bit.
