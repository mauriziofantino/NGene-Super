# NGene documentation

The [operator manual](https://github.com/mauriziofantino/nav-ngene-evo/wiki) covers setup,
receiver operation and configuration in the project's GitHub Wiki. Its pages and GUI
screenshots are maintained in the separate Wiki repository.

The [service documentation](service/README.md) contains engineering details, migration
records and historical validation evidence. It is kept separate from operating instructions.

See [Wiki maintenance](WIKI-PUBLISHING.md) to update the operator manual.
